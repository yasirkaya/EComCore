# EComCore Admin Panel

## 📋 Proje Hakkında

EComCore Admin Panel, e-ticaret platformunun yönetim arayüzüdür. Yöneticilerin ürünleri, kategorileri, siparişleri, kullanıcıları ve diğer sistem bileşenlerini yönetebilmesini sağlar.

## 🏗️ Proje Yapısı

- React tabanlı modern web uygulaması
- TypeScript ile tip güvenliği
- Axios ile API entegrasyonu
- JWT tabanlı kimlik doğrulama

## 🚀 Başlangıç

### Gereksinimler

- Node.js 16.x veya üzeri
- npm veya yarn
- Modern bir web tarayıcısı

### Kurulum

1. Projeyi klonlayın:

```bash
git clone [repository-url]
```

2. Admin Panel klasörüne gidin:

```bash
cd admin-panel
```

3. Bağımlılıkları yükleyin:

```bash
npm install
# veya
yarn install
```

4. Geliştirme sunucusunu başlatın:

```bash
npm start
# veya
yarn start
```

## 📦 Özellikler

- Ürün yönetimi (ekleme, düzenleme, silme)
- Kategori yönetimi
- Sipariş yönetimi ve takibi
- Kullanıcı yönetimi ve rol atamaları
- İstatistikler
- Stok takibi
- Fiyatlandırma yönetimi
