# EComCore Client

## 📋 Proje Hakkında

EComCore Client, e-ticaret platformunun müşteri arayüzüdür. Kullanıcıların ürünleri görüntülemesi, alışveriş yapması ve siparişlerini takip etmesini sağlar.

## 🏗️ Proje Yapısı

- React tabanlı modern web uygulaması
- TypeScript ile tip güvenliği
- Axios ile API entegrasyonu
- JWT tabanlı kimlik doğrulama

## 🚀 Başlangıç

### Gereksinimler

- Node.js 16.x veya üzeri
- npm veya yarn
- Modern bir web tarayıcısı

### Kurulum

1. Projeyi klonlayın:

```bash
git clone [repository-url]
```

2. Client klasörüne gidin:

```bash
cd client
```

3. Bağımlılıkları yükleyin:

```bash
npm install
# veya
yarn install
```

4. Geliştirme sunucusunu başlatın:

```bash
npm start
# veya
yarn start
```

## 📦 Özellikler

- Ürün listeleme ve filtreleme
- Ürün detay sayfaları
- Alışveriş sepeti
- Sipariş takibi
- Ödeme işlemleri
- Ürün değerlendirme ve yorumlar
- Arama fonksiyonu
